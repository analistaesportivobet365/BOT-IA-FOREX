# Pasta de Recursos Estáticos (Assets) do Front-end

Esta pasta é reservada para imagens, logotipos, ícones e marcas-d'água utilizados pelo front-end do Bot IA Forex.

Os elementos visuais, como a marca-d'água vetorial de alta definição da inteligência artificial, foram programados diretamente no componente React `/src/components/BotWatermark.tsx` em formato SVG vetorial infinito para garantir máxima performance, carregamento instantâneo e responsividade perfeita em todas as densidades de tela (Retina, 4K, etc.).
